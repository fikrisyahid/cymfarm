# CymFarm — Dynamic Family Farm Management System

Aplikasi manajemen peternakan & pertanian keluarga yang modular dan *offline-first* (Next.js App Router + Drizzle ORM + Supabase + Dexie.js + React Flow).

## Dokumentasi Lengkap
- 📐 [Arsitektur Sistem & Skema Database (`docs/ARCHITECTURE.md`)](./docs/ARCHITECTURE.md)
- 🛠️ [Panduan Development & Wrapper Commands (`docs/CONTRIBUTION.md`)](./docs/CONTRIBUTION.md)

## Quick Start (Selalu Jalankan dari Root)
```bash
# 1. Install seluruh dependencies
bun install

# 2. Jalankan development server (otomatis sync /.env ke /main)
bun run dev
```
